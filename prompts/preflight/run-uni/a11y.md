# 1\. One-Time Structure, Landmarks & Native Controls

- **Lang, Title & Landmarks:** Set `<html lang="...">` in `index.html`, update dynamic route titles, use semantic landmarks (`<header>`, `<nav>`, `<main>`, `<footer>`), and provide a top-of-tab-order skip link (`#main-content`).  
- **Headings & Native Controls:** Maintain sequential heading order (`<h1>`–`<h6>`) without skipping levels. Structure lists with semantic `<ul>`/`<ol>`. Use native interactive elements (`<button type="button">`, `<a href>`, `<input>`, `<select>`) instead of clickable divs, `href="#"`, or `javascript:void(0)`.

# 2\. One-Time Focus Management, ARIA & Live Regions

- **Focus & Motion Rules:** Enforce visible, high-contrast `:focus-visible` indicators and respect `@media (prefers-reduced-motion: reduce)`. Modals and drawers must trap focus, close on `Escape`, and restore focus to the trigger element on close. Maintain tab hygiene by avoiding positive `tabIndex` values.  
- **Labels & Live Announcements:** Provide explicit accessible names (`aria-label` or visible text), mark decorative graphics as `aria-hidden="true" focusable="false"`, link form inputs via `<label for>`, `aria-describedby`, and `aria-invalid`, and implement a non-disruptive `aria-live="polite"` / `role="status"` region.

# 3\. One-Time Touch Targets, Contrast, Reflow & Print

- **Touch Targets & Color Contrast:** Ensure a minimum 44×44px interactive target area with appropriate spacing. Meet WCAG AA text/icon contrast ratios, support `@media (forced-colors: active)`, and avoid conveying status using color alone by adding text or icons.  
- **Reflow, Tree Semantics & Print:** Provide meaningful image `alt` text, manage `aria-expanded` and `aria-selected` states, ensure responsive reflow at 320px width or 200% zoom without horizontal scroll, and maintain clean `@media print` styles.
