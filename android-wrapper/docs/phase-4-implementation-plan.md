## Phase 4 — Native Backup Vault Mirror & Unified Developer Panel (`android-wrapper/` in AI Studio)

### Prior Assumptions Check
- Confirm Phases 1–3 are complete: `pedigreeBridge` sends `SYNC_BACKUP_SNAPSHOT` (JSON header + trailing `ArrayBuffer`), `OPEN_DEV_PANEL`, and `GET_CONTAINER_INFO`; `MainActivity.kt` currently clears `fileAndExportBridge` on `SYNC_BACKUP_SNAPSHOT` and routes `TYPE_ARRAY_BUFFER` solely to `FileAndExportBridge`.
- Confirm invariants: `app_webview` is never modified or wiped by vault or reset routines, and diagnostic exports never include herd records or PII.
- Confirm `BuildConfig.DEBUG` gates any debug URL override (`https://askkim.github.io/...` only) so R8 (`isMinifyEnabled = true`) strips debug paths from release builds.

### Lean Memory & Token-Spend Discipline (Required Within Phase 4)
- **Diff-First Edits**: Modify existing files (`MainActivity.kt`, `AndroidManifest.xml`, `strings.xml`) strictly via targeted unified diffs/line patches—never rewrite whole pre-existing files. Isolate new code in `NativeBackupVault.kt`, `DiagnosticRingBuffer.kt`, `DeveloperPanelDialog.kt`, and `res/xml/shortcuts.xml`.
- **Scoped Reads & Batched Checks**: Inspect only `grep`-anchored sections (`handleIncomingControlEnvelope`, `TYPE_ARRAY_BUFFER`, `onCreate`/`onNewIntent`, `onDestroy`) instead of re-reading Phases 1–3 files; batch edits before running a single Gradle/test verification pass.
- **Runtime Memory & Token Budgets**: Use fixed-capacity ring buffers, streaming I/O (no duplicate byte buffers), SHA-256 snapshot deduplication, bounded strings, and compact non-null diagnostic JSON to prevent OOM on low-RAM Android 8+ phones and minimize clipboard/AI-triage token spend.

### Implementation Plan
- **Route Binary Frames & Wire Event Hooks (`MainActivity.kt` diff)**: Replace implicit `TYPE_ARRAY_BUFFER` routing with an explicit `PendingBinaryTarget` (`NONE`, `EXPORT`, `VAULT`) set by `BEGIN_BINARY_TRANSFER` / `SYNC_BACKUP_SNAPSHOT` and cleared immediately on frame receipt, mismatch, or `teardownWebView()`. Feed `DiagnosticRingBuffer` from `WebViewClient` (`onReceivedError`, `onReceivedHttpError`, `onRenderProcessGone`), `WebChromeClient.onConsoleMessage` (errors/warnings only), `ExternalNavigationBridge` (blocked/rerouted URLs), and `BackNavigationBridge` (latency/result).
- **Implement `NativeBackupVault.kt` (Streaming + Digest Dedup)**: Process `SYNC_BACKUP_SNAPSHOT` on a single serial `ExecutorService` using `applicationContext` (`shutdown()` in `onDestroy()`). Enforce a strict max snapshot cap (16 MiB; drop buffer reference and log a ring-buffer warning if exceeded). Stream via a 16 KiB `BufferedOutputStream` into `filesDir/pedigree-vault/<ts>_<id>.tmp` while computing SHA-256; if digest + byte length match the latest stored snapshot, unlink `.tmp` and skip rotation (avoiding redundant flash writes/GC churn). Atomically `renameTo` on change, retain newest 5 snapshots, and maintain cached `(count, totalBytes, latestTimestamp)` state for O(1) `GET_CONTAINER_INFO` replies.
- **Implement `DiagnosticRingBuffer.kt` (Zero-Churn Circular Buffer)**: Back the last 100 events with a synchronized fixed `Array<DiagnosticEvent?>(100)`—no `LinkedList` nodes, no `removeAt(0)` shifts, and no disk log files. Truncate messages to `<= 240` chars and strip URL query/hash strings at insert time to bound heap usage and prevent secret/token leakage.
- **Implement `DeveloperPanelDialog.kt` (Lazy, Leak-Free, Compact UI)**: Inflate on demand as an AndroidX `AlertDialog` with a lightweight programmatic `ScrollView` (zero new Gradle dependencies); hold no static `Activity` reference and dismiss in `MainActivity.onDestroy()`. Render WebView runtime info (`SDK_INT`, `WebViewCompat.getCurrentWebViewPackage` + `<109` OPFS notice, `activeOrigin`, build type), the Storage Truth Card (`navigator.storage.persisted()` + on-demand JS quota query with short timeout, async read-only `app_webview` and `filesDir/pedigree-vault/` byte counts, last native backup timestamp), the 100-event log, and actions: `Copy Diagnostic JSON` (compact schema omitting null/empty fields), `Reload App`, `Soft Cache Reset (?emergency_reset=true)` (`webView.clearCache(false)` + `?emergency_reset=true` reload, preserving SQLite/IDB/OPFS), and a `BuildConfig.DEBUG`-only HTTPS URL switcher.
- **Wire Dual Triggers & Static App Shortcut (`MainActivity.kt` + `AndroidManifest.xml` diff)**: Connect `OPEN_DEV_PANEL`, a lightweight 5-tap (`<= 2.5s`) top-right `80dp` corner touch check on `rootContainer` (no extra overlay views/bitmaps), and a static `"Diagnostics"` launcher shortcut (`res/xml/shortcuts.xml` handled in `onCreate`/`onNewIntent`) so diagnostics remain reachable even if React fails to mount.
